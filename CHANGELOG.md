## Исправлено: сайт с базой, засеянной до обновлений
Симптомы: на главной старые релизы вместо свежих, страницы артистов открывались как 404.
Причины: (1) запросы сортировали по колонкам `popularity` и `published_at`, которых нет, пока не
выполнен новый `schema.sql`, — ошибка запроса превращалась в «артист не найден»; (2) база была
засеяна старым каталогом, а сайт в live-режиме читал только её.
- Сортировка по необязательным колонкам перенесена на клиент; сервер сортирует только по базовым.
- Каждый запрос обёрнут в `safe()`: при ошибке — предупреждение в консоли и локальные данные, страница не падает.
- Пустые поля артиста и пустые блоки дополняются из локального каталога; релизам без даты дата берётся
  из каталога; релизы из каталога новее самого свежего в базе добавляются (`enrichReleases`, с тестами).
- Пустая таблица концертов — показываются туры из каталога.
- `npm run seed` работает и до применения блока автосинхронизации в схеме.

## Исправлено: на сайте пропали свежие релизы и обложки
Причина — две мои правки из прошлого обновления, сработавшие вместе: из витрины убрал подмешивание
локального каталога (по отчёту, P1-11), а бережный seed заполнял только пустые таблицы. В итоге база,
засеянная раньше, так и оставалась без новых релизов, и подтянуть их было нечем.
- Seed в бережном режиме добавляет отсутствующие записи по ключу и дописывает пустые дату и обложку.
  Проверено на PostgreSQL 16 + PostgREST: устаревшая база получает 10 новых релизов Доры с обложками,
  скрытый в админке релиз не дублируется, повторный запуск ничего не меняет.
- Новый источник синхронизации — публичный API Deezer (без ключа): обложки 1000 px, точные даты,
  популярность треков. Работает и без расширенной квоты Spotify. Поле Deezer в админке, выбор тёзок.
- Релизы Доры 2024–2026 в каталоге с обложками и датами из Deezer.
- schema.sql: представления пересоздаются через drop + create (create or replace падал при новой колонке).

## Синхронизация без командной строки
- Секрет расписания генерируется в Vault прямо в `cron.sql` и сверяется функцией `check_sync_secret()`:
  вводить секреты руками не нужно. `SYNC_SECRET` в секретах функции по-прежнему поддерживается.
- `npm run build:function` собирает функцию в один файл (`supabase/functions/sync-catalog.bundle.ts`)
  для вставки в редактор Supabase Dashboard.
- Развёрнуто на проекте: функция `sync-catalog` (без проверки JWT — авторизация внутри), расписание раз в 30 минут.
  Пробный запуск для Доры: найдена в Deezer, +21 релиз с датами и обложками, +3 трека.

## Адаптивная сетка админки
- Брейкпоинты: телефон ≤600, планшет 601–900, ноутбук 901–1279, десктоп 1280–1599, широкий ≥1600.
- Контент занимает ширину экрана до 1760px; «Обзор» на широком — три колонки (посещаемость,
  популярное, дела), синхронизация и место — рядом; ростер — карточки в 2–3 колонки;
  форма артиста — разделы в две колонки; длинные списки ограничены читаемой шириной.
- Планшет: свои двухколоночные раскладки вместо растянутой мобильной.
- График посещаемости в первые дни не рисует один столбик во всю высоту и объясняет, что данные копятся.
- Проверено на 1920, 1440, 1024, 768 и 390px: без горизонтальной прокрутки.

## Документы, футер, язык, фильтры, концерты, мерч
- Все документы сайта в админке: тексты (политика, соглашение) и файлы (СОУТ, СБД — PDF загрузкой или
  ссылкой), галочка «Ссылка в футере», порядок. Таблица `pages`: `kind`, `file_url`, `show_in_footer`,
  бакет `docs`. Страница «Документы» и футер берут список из базы.
- Футер: знак и название, кнопки «Пригласить артиста» / «Отправить демо», колонки Лейбл · Работа с нами ·
  Связаться (почты, соцсети) · Документы; внизу копирайт и пометка о неофициальном сайте.
- Язык: кнопка с глобусом в шапке и список с подписями («Русский — этот сайт», остальные — официальные
  сайты лейбла с адресами); в мобильном меню — тот же список.
- Фильтры: свой выпадающий список в стиле сайта вместо системного (клавиатура, поиск по буквам, Esc).
- Типы релизов: Синглы · EP · Альбомы · Сборники со счётчиками; пустые — недоступны.
- Концерты: затемнение под заголовком и цифрами, фото приглушены — текст читается и на телефоне.
- Мерч: нейтральный фон карточки без цветного градиента.

## Соцсети лейбла, языки с флагами, страница вещи
- Соцсети лейбла правятся в админке → «Лейбл» (таблица `settings`), выводятся в футере отдельной
  строкой по центру кнопками 80px (64px на телефоне), в мобильном меню и на «Контактах».
- Языки: флаг и название, без пояснений и стрелок; флаги — SVG (эмодзи-флаги на Windows не рисуются).
- Мерч: без фона под карточкой; у каждой вещи своя страница /merch/:id — главное фото и галерея,
  цена и статус, размеры, описание, кнопка покупки, «Ещё от артиста». В админке: «Ещё фото»
  (порядок, удаление), описание, размеры.
- Админка: вертикальный ритм разделов задаёт сетка (`.a-stack`), заголовки блоков не прилипают к карточкам.
